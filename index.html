Política de Privacidade — APPjogos

Última atualização: 13 de agosto de 2026

Esta política explica quais dados o aplicativo APPjogos processa, para quê, e quais direitos você tem sobre eles. Ela se aplica ao app disponível para Android e iOS.

2. Sobre o aplicativo

O APPjogos é um app de jogos para grupos e festas, com mecânica de "passar o celular" entre os jogadores. Ele funciona 100% offline — não existe servidor próprio, nem cadastro, login ou conta de usuário.

3. Quais dados processamos

3.1 Dados salvos só no seu aparelho

  • Histórico dos itens já sorteados em cada jogo, para evitar repetição em partidas seguidas.
  • Preferência de tema (claro/escuro).
  • Status da compra do pacote premium, para manter o conteúdo liberado sem depender de conexão o tempo todo.

Esses dados ficam salvos localmente no armazenamento do seu próprio aparelho. Nunca são enviados para nós ou para qualquer servidor — porque não existe servidor. São apagados automaticamente se você desinstalar o app, ou manualmente se limpar os dados do app nas configurações do sistema.

3.2 Dados processados por terceiros

Anúncios (Google AdMob). Usamos o AdMob para exibir anúncios entre partidas. Esse serviço usa o identificador de publicidade do seu aparelho (IDFA no iOS, GAID no Android) e outros dados técnicos para exibir e medir anúncios, podendo personalizá-los conforme suas preferências de rastreamento. No iOS, isso passa pelo prompt de rastreamento do próprio sistema (App Tracking Transparency) antes de qualquer coleta; no Android, pode ser ajustado nas configurações de anúncios do Google. O Google trata esses dados sob sua própria política: policies.google.com/privacy.

Compras dentro do app (App Store / Google Play). Quando você compra o pacote premium, o pagamento é processado inteiramente pela Apple ou pelo Google. Não temos acesso a dados de cartão nem armazenamos qualquer informação de pagamento — recebemos apenas a confirmação de que a compra foi concluída, para liberar o conteúdo correspondente.

3.3 Sensores do aparelho

O jogo "Celular na Testa" usa o acelerômetro para detectar quando você inclina o celular. Essa leitura é processada apenas durante a partida, localmente no aparelho, e não é armazenada nem transmitida para lugar nenhum.

3.4 O que não coletamos

Não pedimos nem acessamos nome, e-mail, localização, contatos, câmera, fotos, ou qualquer identificador pessoal direto. A permissão de áudio do app existe apenas para tocar efeitos sonoros do jogo — nunca para gravar. Não há microfone, cadastro, login ou conta de usuário em nenhum momento.

4. Com quem compartilhamos dados

Só compartilhamos dados com os provedores estritamente necessários para as duas funções citadas acima:

  • Google (AdMob) — exibição e medição de anúncios.
  • Apple / Google — processamento das compras dentro do app.

Não vendemos dados a ninguém, nem compartilhamos com qualquer outro terceiro além dos citados.

5. Transferência internacional de dados

Os provedores citados acima (Google, Apple) podem processar dados em servidores localizados fora do Brasil, seguindo suas próprias políticas de privacidade e certificações de conformidade.

6. Classificação etária e conteúdo sensível

O APPjogos é voltado ao público em geral, mas contém seções de conteúdo mais adulto/ousado, sempre sinalizadas dentro do próprio app antes de o jogador optar por acessá-las:

  • Cartas "picantes" do jogo Verdade ou Desafio.
  • "Modo Viajado" do Termômetro da Opinião — temas mais abstratos, sugerido no próprio app como opção para jogar bebendo.

Recomendamos supervisão de um responsável para o uso por menores de idade nessas seções específicas. Não coletamos intencionalmente dados de menores de 13 anos; caso um responsável identifique que isso ocorreu, pode contatar o e-mail abaixo para solicitar a remoção.

7. Seus direitos (LGPD — Lei 13.709/2018)

Como não mantemos servidor nem banco de dados com informações pessoais identificáveis — o conteúdo relevante fica só no seu aparelho — a maior parte dos seus dados já está sob seu controle direto: basta desinstalar o app ou limpar seus dados nas configurações do sistema.

Ainda assim, no que for aplicável ao tratamento feito por nós ou por nossos operadores (Google, Apple), você tem os direitos garantidos pela LGPD:

  • Confirmação da existência de tratamento de dados.
  • Acesso aos dados.
  • Correção de dados incompletos, inexatos ou desatualizados.
  • Anonimização, bloqueio ou eliminação de dados desnecessários.
  • Portabilidade.
  • Eliminação dos dados tratados com base em consentimento.
  • Informação sobre com quem compartilhamos dados.
  • Revogação do consentimento.

Você também pode apresentar reclamação à Autoridade Nacional de Proteção de Dados (ANPD): gov.br/anpd.

8. Segurança

Como não existe servidor nem banco de dados centralizado com informações de usuários, o principal ponto de atenção fica no próprio aparelho de cada pessoa — recomendamos manter o sistema operacional atualizado e usar bloqueio de tela. Os provedores terceiros citados (Google, Apple) mantêm suas próprias práticas de segurança, descritas em suas respectivas políticas.

9. Alterações nesta política

Esta política pode ser atualizada quando o app mudar — por exemplo, se um novo recurso passar a processar um novo tipo de dado. A data no topo desta página é sempre a da versão mais recente. Mudanças relevantes serão sinalizadas dentro do próprio app.
